# Responsive UX

Inspect the actual component and its content at relevant widths; do not only scale dimensions. At narrow widths, decide how tables become useful (priority columns, horizontal scroll with cues, or alternate row cards), how navigation changes, where primary actions remain reachable, and how dense forms and amounts wrap. Maintain readable line lengths, non-overlapping controls, visible focus, and touch targets sized for reliable use. Avoid hover-only affordances and fixed bottom bars that cover content or keyboard input. Test long labels, large values, validation messages, and zoom. Respect reduced motion and preserve access to every essential task.
