# Intent Discovery

For the requested screen or component, establish: primary user and context; top task; information needed to complete it; the most costly likely mistake; and what success looks like. Use the prompt and repository evidence first. Ask no more than a few focused questions, and only if an answer changes the implementation materially. Otherwise state assumptions and proceed. Treat the worst-case scenario as a design constraint: add prevention, confirmation, undo, or recovery as appropriate without adding needless friction to low-risk actions.
