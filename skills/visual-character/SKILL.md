# Visual Character

Before implementing a new screen, make one explicit choice for each axis: type, color, space, and finish. Base choices on product purpose, audience, existing brand, and repository assets. Express reusable choices as tokens; use existing product conventions where available. Distinctiveness should come from a few deliberate, repeatable decisions, not visual noise.

When auditing a generic-looking hero or marketing screen, check for a floating card, gradient blob, and row of social buttons used as a default composition. Do not treat any one of these as automatically wrong; replace the bundle when it is unrelated to the product's actual subject or offers no useful evidence. Prefer product-specific imagery, content, and hierarchy. Avoid arbitrary gradients, generic card piles, excessive rounding, decorative shadows, and inconsistent icon styles.

Keep icon families coherent: inspect stroke weight, optical size, alignment, and semantic color. The account's public icon example calls out consolidating stroke width, size choices, and accent use; treat these as consistency checks, not immutable numeric limits. Check contrast and hierarchy after applying the choices; document new system-level decisions in DESIGN.md.
