# Form UX

Group fields by user mental model and task order. Use persistent visible labels, correct input types, useful autocomplete attributes, and concise hints only where they prevent errors. Choose defaults conservatively; never preselect a consequential or privacy-sensitive choice without justification. Validate on blur or submit rather than interrupting while the user is still typing; use inline validation for clear, timely feedback. State requiredness and constraints before failure. Keep valid input after errors, move focus to an error summary when appropriate, and associate error text with its field. Use progressive disclosure only to reduce irrelevant complexity, not to hide required terms or choices. Consider mobile keyboards, password visibility, file constraints, and accessible grouping.
